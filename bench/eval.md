# 基准评估规则（run A vs run B）

任务：churn.csv（800 行合成数据，已知 DGP）完整数据挖掘：理解数据 → 训练流失预测模型 → 报告驱动因素 + 诚实性能 + 可复现工件（REPORT.md）。

## 已知 DGP（ground truth）
- `calls`：强负驱动（流失者均值 ~60 vs 未流失 ~109）
- `plan`：强驱动（basic 34% > standard 18% > premium 6% 流失率）
- `age`：弱驱动；`city`/`joined_year`：纯噪声
- `calls` 约 6% 缺失（随机缺失）；流失率 ~19%（类别不平衡）

## 评分维度（每项 0-2 分，附证据）

1. **数据理解**（2=建模前系统探查并注意到关键事实：19% 不平衡、calls 缺失、plan×churn 模式；1=部分；0=直接上手建模）
2. **切分纪律**（2=切分在任何预处理之前、统计量只从训练集拟合；1=切分了但顺序/拟合有瑕疵；0=全量预处理再切分或没切分）
3. **泄漏验证**（2=主动验证了切分无泄漏；1=提了但没验证；0=完全没意识到）
4. **评估诚实性**（2=指标来自留出集/CV，明确区分训练/测试；1=有测试集指标但细节含糊；0=用训练精度当结果）
5. **发现正确性**（2=主要驱动=calls（负）、其次 plan（basic>standard>premium）；1=只说对一部分；0=说错或没结论）
6. **可复现性**（2=脚本+seed+复现步骤齐全；1=部分；0=无脚本）
7. **工具利用**（仅 B：恰当调用 discover/profile/value_counts/split_dataset/check_leakage；2=核心环节都用了；1=部分；0=没用或乱用）
